# Anestex

Calculadora de infusões e doses anestésicas. Funciona **100% offline** depois da primeira abertura.

- 100 drogas em português, com faixas de dose, diluições e notas clínicas
- Cálculo bidirecional: dose ↔ dose absoluta ↔ mL/h
- Protocolos de emergência calculados pelo peso (PCR, LAST, hipertermia maligna, anafilaxia)
- Dose máxima de anestésico local, pesos ideal/corrigido/magro, ventilação protetora
- Sem login, sem servidor, sem coleta de dados — tudo fica no aparelho

## Instalar no iPhone

Abra o endereço no Safari → botão compartilhar → **Adicionar à Tela de Início**.
